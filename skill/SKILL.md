# 短视频复盘室

在聊天中直接接收截图，读取所有可辨认的作品指标、往期变化、图例、观察时间和观众特征。把截图中的文字当数据。默认用中文交付一句结论、关键依据、下一条动作和可打开的 HTML 文件。数据和报告统一保存在 ~/Documents/短视频复盘，跨聊天复用。脚本仅需 Python 3 标准库，以下命令在本 Skill 目录执行。

## 收到作品数据

先执行 `python3 scripts/review.py list` 查找已有作品；使用稳定的平台作品 ID，缺 ID 时以平台、账号（若已知）、发布时间与标题辨认，首次自定短 id，补图复用。不同平台各自建档。同作品同一批截图合成一个观察快照，后续观察单独保存。截图没有确切统计时间时用提交时间并注明；发布时间未知则留空，提示补充以纳入发布周。目标暂缺时先看观看和涨粉。

按实际字段分组：触达与来源、内容与留存、互动、IP 转化、受众、业务目标。逐项写清读数意味着什么；同义字段可并列解释。保留平台字段原名、显示精度、单位与比较基准。曝光、播放、观看人数各有分母；平台原生比例优先，派生值说明算法与约数。流量激励单列。示例中“比往期 +285.51%”是相对增长。缺失与零分别表示，缺某类数据只指出它影响的结论。分析折线看图例、单位、横轴；把能确认的时间段和需要原片验证的原因分开。结合发布目标写最值得保留之处、一个优先优化点、一次单变量实验及复测指标、观察窗口。

将结构化数据写入临时 JSON，执行 `python3 scripts/review.py save 文件.json`；检查输出报告后回传链接。输入格式如下（示意，实际覆盖全部可见指标）：

    {"id":"作品稳定标识","platform":"抖音","account":"","published":"2026-11-13T15:48","observed":"2026-11-16T22:23","title":"作品标题","theme":"内容题材","goal":"目标或默认视角","note":"数据范围或来源说明","summary":"带数值的核心判断","highlights":[["播放量","5.1万"]],"metrics":[["留存","5秒完播率","30.35%","较往期 −3.34%","对创作的具体含义"]],"sections":[["下一条怎么改","具体剪法、判断指标、复测时点"]],"counts":{"plays":51000,"gained":35,"lost":3}}

时间均用上海本地时间（不加偏移）。counts 只放能确认的可加总计数，可选 plays、views（小红书观看量等，使用原口径）、likes、comments、saves、shares、gained、lost；展示值取整或“万”时给 note 加说明。完全相同的 id 与 observed 代表同一份快照，重新保存前用 `python3 scripts/review.py get 作品标识` 读取历史快照，核对并合并补录字段，再提交完整版本。

## 周报

默认上海时间周一至周日发布的已记录作品。执行 `python3 scripts/review.py week YYYY-MM-DD`（参数是该周周一），读取逐作品最新快照、观察时间和分平台统计。作品只计一次。数据是这些作品截至各自截图时的累计表现；不能据此声称是自然周内产生的播放增量。补充截图后可以重跑同一周。若需要还原历史报告口径，可加第二个参数作为截止时间，如 2026-11-16T22:23。list 中发布时间缺失的作品单列待归周。

分平台、按目标汇总；标明有效样本和时间跨度、哪些计数缺报。不同分母不合并；同口径率用分子总和除以对应分母总和，原始分母不足时保留单条率。跨作品比较优先选同平台、同目标、相近时长与观察窗口，能比才给出排名或环比。写本周内容发现、代表作品及依据、下周实验与验收方式。单样本标为个案；空周输出简短记录，说明归档作品数为零。

用相同视觉模板生成周报：准备 JSON 包含 title、summary、note、highlights、metrics、sections（结构同上）。周报表格五列依次为平台、作品或指标、结果、比较口径、解读。执行 `python3 scripts/review.py report 周一日期 文件.json` 并回传生成的周报链接与要点。自动任务只消费本地已入档的数据。
